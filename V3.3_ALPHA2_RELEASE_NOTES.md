# Pub Quiz Powerhouse 3.3.0-alpha.2 — Classic Quiz Stage B

**Development build. Do not replace your live v3.2 Render deployment yet.**

## What changed since Alpha 1

### Classic Quiz question flow
- A small host-only question status pill shows **OPEN, LOCKED, REVEALED, MARKED or FINALISED**.
- Classic multiple-choice and typed-answer submissions are locked before an answer is revealed. The reveal action closes submissions automatically if the host has not done so already.
- Every submitted response must be marked before points can be awarded.
- **Finalise: 0 points** explicitly closes a revealed question with no correct answers. A deliberate **Skip for 0 points** action requests confirmation and records a zero-point result.
- **Next question** and **Skip to next round** no longer silently pass an unfinalised question in the new experiences. Written rounds keep their established manual scoring procedure.
- A scored question can be reopened for marking without deleting unrelated later scores or manual adjustments. Re-awarding remains protected from duplicates.

### Persistent question records
- Each question now preserves its submission order, answer text/selection, marking decisions, reveal status and award reference in the quizmaster's saved browser state (`questionSessions`).
- Moving backwards to an earlier question restores its previous state rather than opening a fresh empty answer queue.
- Restored questions are issued a fresh question instance ID so delayed phone messages from a different question are ignored.
- Reset Scores now clears question award records and the saved-question ledger together.
- Fixed an **existing initialisation-order bug**: saved games could be silently discarded on page refresh because the normalisation routine referenced an uninitialised function expression. These helpers are now safely declared before use.

### Quizmaster usability
- Classic typed-answer rounds allow the host to enter or revise a team's typed response without requiring a phone, while the question is open.
- Host instructions now describe Classic versus Game Show scoring more accurately.
- The previous Quiz Society characters, three states each, sound effects, music and Render-compatible server are preserved unchanged.

## Windows test instructions

1. Download the Alpha 2 ZIP and extract it to a **new folder** (not your working v3.2 folder).
2. Double-click **`start.bat`**. The first run installs dependencies if necessary. Keep the black window open.
3. In Chrome, open `http://localhost:3000` if the browser does not open automatically.
4. In Setup select **Classic Pub Quiz**. Create at least two teams and start a multiple-choice round.
5. Submit answers; press **Close answers**, then **Lock, reveal and mark**, inspect the marks and choose **Award points** or **Finalise: 0 points**.
6. Advance one question, return with **Previous**, confirm the original answers remain visible, and try **Reopen marking** on the scored question.
7. Refresh the browser and confirm the same scores, questions and marks remain. Separately choose **TV Game Show** in a new quiz to test speed bonuses.
8. Test phone controllers and your TV with a local or preview instance before considering a production release.

# Pub Quiz Powerhouse — v3.3.0-alpha.3 (Stage C, TV Game Show)

**Status: Development preview only. Do not overwrite your working v3.2 Render deployment.**

## Implemented

- **Exclusive buzzer rounds.** In TV Game Show mode, only the first host-accepted team claims a live turn. Other teams cannot queue buzzes during that attempt. The host can judge the active team as correct or wrong.
- **Wrong-answer recovery.** After a wrong answer, that team is ineligible to buzz again on the same question. The round reopens to remaining eligible teams while time remains. With all teams exhausted or the timer expired, the host reveals the answer and finalises it without correct-answer points.
- **Correct-answer resolution.** Correct judgement awards the configured base points, reveals the answer and closes the buzzer round. The question cannot be awarded twice.
- **Optional wrong-answer penalties.** When enabled, penalties share a question-scoped history group with the winning award. Restarting attempts, skipping the question, or re-running a finalised buzzer question reverses the appropriate deductions/awards. *Finalise without a correct answer* preserves eligible penalties (it means zero **correct-answer** points, not necessarily zero net change).
- **Host controls.** Added explicit active-turn messaging and a **Re-run question** button on scored buzzer rounds. Re-running reverses that question's score changes and clears all attempts. The host cannot reveal a still-active attempt, or manually reopen an expired timer without resetting it.
- **TV presentation.** Distinct gold *FIRST BUZZ / EXCLUSIVE TURN* and *CORRECT BUZZER / POINTS AWARDED* banners, dimmed inactive teams, and compact ten-team layout at 1280 × 720. Reduced-motion accessibility preferences are respected.
- **Phone-facing state.** Sends the active team, eligible count, and already-judged wrong attempts (without revealing the actual answer). Phones show an explicit *your turn*, *other team answering*, or *you've already tried* message.
- **Saved-state compatibility.** Earlier v3.3 Alpha 2 parallel-pending buzzer states are sanitised to one active contender on load. Classic mode and v3.2 legacy scoring paths are preserved.
- **Existing content.** The 24 Quiz Society avatars (72 reaction WebPs), quiz bank, sound library, startup files and Render-compatible server remain intact.

## Scoring and timing specifics

| Scenario | Result |
| --- | --- |
| Fastest valid buzz | Claims the turn; all other buzzers lock until host judges |
| Incorrect attempt | Zero points, unless optional wrong-buzz penalty is enabled; team is ineligible for this question |
| Another correct team | Gets question base points; no simultaneous speed bonus in exclusive mode |
| All wrong | Host reveals and finalises; question awards no correct-answer points |
| Timer expires while buzzers open | No new valid claim; host can reveal/finalise or explicitly reset the timer |
| Buzz accepted just before timeout | Host can still judge that active attempt; timer pauses during the attempt |
| TV Game Show choice/typed round | Unchanged: all correct earn base points, first +2, second +1 |
| Classic Pub Quiz | Unchanged: each correct answer earns the question's points |

Buzzer arbitration is by **arrival at the quizmaster's browser**, not a guaranteed millisecond-accurate comparison between different phone networks. This prevents phone clock manipulation but cannot remove real-world network latency effects.

## Not yet tested / still to address

1. Real phones on mixed connections, TV/quizmaster socket relay, ordering under network latency, reconnection, and replay after live Render service restarts.
2. Secure binding between an individual phone session and its claimed team. **The inherited v3.2 phone/team identity spoofing limitation is still unresolved.** Do not treat a public room code as an authentication credential.
3. Persistence across loss of the quizmaster device. Saves still live in the browser's local storage, not a dedicated cloud database.
4. `npm test` including the existing Socket.io relay test: `npm ci --offline` cannot install an uncached dependency (`xmlhttprequest-ssl`) in this environment. Pure Node and headless-browser tests passed independently.
5. Accessibility and responsive QA on physical TV browsers, iOS Safari, and Android Chrome.

## Windows testing

1. Extract `Pub-Quiz-Powerhouse-v3.3-Alpha3-TV-Game-Show.zip` into a **new folder**.
2. Double-click `start.bat` (install Node.js first if missing). If necessary, wait for npm dependency installation on first run.
3. Open `http://localhost:3000`, choose **TV Game Show** in Setup, then change one round to **Buzzers**.
4. Start a quiz. Buzz from one team; check every other buzzer stays locked. Mark wrong; confirm other teams can buzz, but the wrong team cannot. Mark the next one correct and check the score and TV result banner.
5. Test penalty-on, all-wrong, expired timer, re-run question, and a **Classic Pub Quiz** round as a regression check.
6. Keep v3.2 live on Render while testing this alpha. Do not merge `feature/v3.3-dual-experience` into `main` yet.

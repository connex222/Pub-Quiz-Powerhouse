# Sound asset library — Quiz Night Live

All user-supplied original audio files are preserved in `public/assets/sfx/` and `public/assets/music/`. This redesign uses selected cues for joins, buzzes, correct/wrong answers, and wins. The unused assets remain in the package for later game features. Music is OFF by default and can be enabled under Game settings.
